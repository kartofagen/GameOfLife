Это модификация *Conway's Game of Life*

## Правила

### Обычные правила *Conway's Game of Life*:
- Клетка выживает при 2-3 соседях
- Клетка умирает при <2 или >3 соседей
- Новая клетка рождается при 3 соседях

Таким образом, можем выделить следующие параметры:
- `Min Survive Neighbors` - минимальное число соседей для выживания
- `Max Survive Neighbors` - максимальное число соседей для выживания  
- `Reproduce Neighbors` - число соседей для размножения

### Отравы:

Реализованы в виде зон с отличными от обычных правилами:
| Название | `Min Survive Neighbors` | `Max Survive Neighbors` | `Reproduce Neighbors` |
|----------|----------|----------|----------|
| Conway | 2 | 3 | 3 |
| Дихлофос | 3 | 4 | 3 |
| Яд (гель типа) | 2 | 0 | 3 |
| Ловушка  | 1 | 1 | 3 |

В этих зонах тараканам выживать сложнее.

## Режимы:

### 1. Free Mode
- Неограниченное создание и редактирование тараканов и структур из них
- Неограниченное размещение отрав

### 2. Tournament
Соревновательный ПВП-режим для 2 игроков (hot seat на одном устройстве):

**Игрок 1: ДЕЗИНСЕКТОР**
- Размещает до 50 отрав
- Его цель: уничтожить всех тараканов до единого

**Игрок 2: ТАРАКАНИЙ БОГ** 
- Размещает до 1000 тараканов
- Его цель: сохранить хотя бы одного

То есть это игра с нулевой суммой.

## Управление

- **ЛКМ** - размещение тараканов/отрав/тараканьих структур
- **ПКМ** - удаление тараканов/отрав
- **R** - поворот структуры при размещении
- **Space** - запуск/пауза симуляции
